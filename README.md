# qari-website

Minimal static site for [Qari](https://github.com/) — currently just the privacy policy
required for App Store / Play Store submission, plus a placeholder landing page.

- `index.html` — landing page
- `privacy-policy.html` — privacy policy (linked from App Store Connect / Play Console)

No build step. Deploy as a static site (e.g. Vercel, GitHub Pages) with no framework
preset — it's plain HTML/CSS.
